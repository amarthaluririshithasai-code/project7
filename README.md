# Project 7 – String-Based Examination Answer Evaluation

## Description
The String-Based Examination Answer Evaluation System is a Python program designed to evaluate students' examination answers by comparing them with a predefined answer key. It identifies correct, incorrect, and unanswered questions and calculates the final score based on the marking scheme.

## Objectives
- To understand string operations in Python.
- To store answers using lists.
- To compare student answers with a predefined answer key.
- To count correct, incorrect, and unanswered questions.
- To calculate the final examination score.

## Concepts Used
- Strings
- Lists
- For loops
- Conditional statements
- String methods (`upper()`)
- Arithmetic operations
- Counters

## Assumptions
- The examination contains five questions.
- Each correct answer carries 2 marks.
- Each incorrect answer has a penalty of 0.5 marks.
- Unanswered questions carry zero marks.
- Answers are evaluated without considering uppercase or lowercase differences.
- The answer key is predefined.

## Marking Scheme

| Answer Type | Marks |
|---|---:|
| Correct Answer | +2 |
| Incorrect Answer | -0.5 |
| Unanswered | 0 |

## Sample Output 1

```text
Student Name: Ram

Correct Answers: 5
Incorrect Answers: 0
Unanswered Questions: 0

Final Score: 10.0 / 10
```
